# 設計 slop：為什麼 `design/vibe-slop/` 的十頁是反例

修改本專案任何視覺樣式前先讀這份。`design/vibe-slop/` 裡的十個頁面是刻意做出來的 **slop**：
一眼就能認出「這是 AI 隨手生成的」的設計。它們保留下來當對照組，不是候選方案。

## slop 的判準

一個檢查就夠：**把桃園、天氣、十三區全部拿掉，這個頁面還成立嗎？**
成立，就是 slop。它的外觀來自「某個流行模板」，不是來自這個主題。

slop 有三個共同症狀，十頁全部中：

1. **視覺語言與主題無關。** 紫色漸層、霓虹、像素風，套在天氣、記帳、待辦清單上都一樣。
2. **裝飾取代資訊。** 圓角、陰影、玻璃、發光、徽章蓋在每個區塊上，層級被抹平，讀者分不出「現在 31°」和「氣壓 1006」哪個重要。
3. **只有一種尺寸的想法。** 整頁用同一個圓角、同一種卡片、同一個陰影，等於沒有做決定。

## 本專案的視覺語言（正向目標）

色票、字級、圓角的權威來源是 `index.html` 的 `:root` 區塊，別在這裡抄一份。這裡只記錄看程式碼看不出來的**理由**：

- **顏色來自桃園的地景。** 表面色是「台地霧色」，墨色是「埤塘深墨」，主色 teal 是埤塘，氣溫用「台地紅土」。任何新顏色先問：這對應桃園的哪一樣東西？答不出來就用既有 token。
- **深色主題是海軍藍，不是綠、不是純黑。** 這是使用者明確要求過的。
- **字體分工固定。** 數字用 Bricolage Grotesque，中文用 Noto Sans TC，兩者之外的字體需要理由。
- **圓角 6px，一種。** 卡片邊界靠 1px hairline，不靠陰影。
- **一頁只有一個亮點：十三區 3D 地圖。** 其他區塊安靜，讓地圖是唯一會動、會被記住的東西。
- **資料是即時的。** 所有數字來自 Open-Meteo（可選 CWA）。任何寫死數字的區塊都是示範，必須標示。

## 十個反例：症狀 → 改法

| 檔案 | 流派 | 為什麼是 slop | 在本專案該怎麼做 |
|---|---|---|---|
| 01-glass | 紫藍漸層玻璃擬態 | `#667eea→#764ba2` 是 AI 生成的預設色；模糊玻璃卡讓文字對比失守；emoji 當圖示無法換色與縮放。 | 顏色回到地景 token；圖示一律 inline SVG；卡片邊界用 hairline。 |
| 02-saas | Tailwind SaaS 落地頁 | 對天氣頁而言，定價、見證、Logo 牆是**不存在的內容**；漸層標題字與 indigo-600 按鈕是框架預設，不是決定。 | 頁面只放讀者要的：現在、接下來、哪一區。沒有內容的區塊直接刪，不用版面填。 |
| 03-neon | 賽博龐克霓虹 | 三層 text-shadow 發光降低可讀性；全部大寫英文與桃園使用者無關；掃描線是純裝飾。 | 動態只留一處（地圖）；語言與字體為中文讀者設定。 |
| 04-bento | Apple 便當格 | 每格一個數字、同一圓角、同一陰影，層級被抹平；28px 圓角與 160px 細體是抄來的，不是算出來的。 | 大數字只給「現在氣溫」一個；其他細節用清單，不用格子。 |
| 05-brutal | Neubrutalism | 黃底黑框硬陰影是純風格宣言，跟氣象資料沒有關係；跑馬燈把資訊變成噪音。 | 版面安靜，讓數字與地圖說話。 |
| 06-terminal | 駭客終端機 | ASCII 表格在手機上無法排版；綠字黑底對長時間閱讀不友善；「hacker」是給開發者的自我投射，不是給桃園市民。 | 表格用真正的 HTML `table`，隨寬度重排；配色從 token 取。 |
| 07-admin | 管理後台模板 | 側欄導航、KPI 卡、「較昨日 ↑2.1°」、甜甜圈圖是企業儀表板的**形狀**，天氣頁沒有這些流程；十三區用資料表加狀態膠囊，是把地圖降級成試算表。 | 十三區永遠用地圖呈現；比較昨天的數字只在真有意義時才出現。 |
| 08-kawaii | 粉彩可愛風 | 吉祥物、漂浮愛心、emoji 是氣氛，不是資訊；粉彩對比度普遍不足。 | 溫度感靠色階（`--t1`…`--t5`），不靠裝飾。 |
| 09-nimbus | Vercel／Linear 純黑開發者頁 | 純黑 `#000`、13px 小字、「Powered by AI ✦」徽章、「Trusted by」灰色字標，全是開發者工具的視覺借用；英文標題對本地讀者是隔閡。 | 深色主題用海軍藍 token；正文字級 16px；中文優先。 |
| 10-pixel | 8-bit RPG 像素 | HP／MP 條把濕度、紫外線包成遊戲數值，讀者得先解碼；Press Start 2P 中文不支援，必須混第二套字體。 | 數值用它本來的單位與尺度（%、hPa、UV 指數）直接呈現。 |

## 跨十頁重複出現、以後一律不要的手法

每一條後面都是替代做法，改樣式時直接照做：

- **漸層當背景** → 單一表面色 token，深度靠 hairline 與留白。
- **每個區塊都是圓角卡片** → 只有需要被「拿起來」的東西才是卡片（例如浮動的工具提示）；其餘用標題與間距分區。
- **陰影疊在陰影上** → 一頁最多一種陰影，用在最多一種元件上。
- **emoji 當天氣圖示** → 單一筆觸風格的 inline SVG，可換色、可縮放。
- **「AI」「Powered by」徽章** → 頁面不需要宣稱自己是什麼；資料來源寫在頁尾。
- **假內容撐版面**（定價、見證、Logo 牆、「10,000+ 使用者」） → 沒有的東西不放。
- **英文標語配中文內文** → 標題與內文同一語言，中文優先。
- **Inter 當「安全」字體** → 用專案既有的兩套字體。
- **全頁動畫**（漂浮、閃爍、掃描線、跑馬燈） → 動態只留一處，且尊重 `prefers-reduced-motion`。
- **一個數字一個大格子** → 大字只給最重要的一個數字。

## 交付前的檢查

重設計或改樣式的工作，做到以下五項全部成立才算完成：

1. 拿掉「桃園」與天氣資料後頁面**不再成立**（視覺語言綁定主題）。
2. 頁面上的每個顏色都能對應到 `index.html` `:root` 的 token，或有寫下理由的新增。
3. 只有一個視覺亮點，且是十三區地圖。
4. 手機寬度（390px）沒有橫向捲動，表格自行重排。
5. 淺色與深色主題都讀得清楚，深色是海軍藍。
