# WeatherHtmlUI

## Project goal

建立一個 HTML page 追蹤桃園市（Taoyuan City, Taiwan）的氣象狀況，使用現代且人性化的 UI 界面。

A single HTML page that tracks current weather conditions for Taoyuan City, Taiwan, with a modern, humane UI.
