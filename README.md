# 桃園天氣

追蹤桃園市十三個行政區天氣的單頁網站。只有一個 `index.html`，沒有建置步驟。

## 使用

直接用瀏覽器開啟 `index.html` 即可。若要在手機或區網其他裝置看，可以起一個本機伺服器：

```sh
python3 -m http.server 8000
# 然後開 http://localhost:8000/
```

頁面每 10 分鐘自動更新，也可以按右上角「重新整理」。最後一次資料會存在瀏覽器裡，離線或斷網時先顯示舊資料並標記時間。

## 頁面內容

視覺方向是 `design/redesign/07-xiangsu.html`：NES 固定調色盤、黑底白框、Press Start 2P 配 DotGothic16。每個顏色有一個用途：金＝太陽與標題、天藍＝雨與水、紅＝高溫與警示、綠＝空氣良好。

- **天空區**：白天天藍、夜間深藍的一整塊平塗，放目前氣溫、天氣與體感。點區名可切換十三區。
- **預報**：一句話。由逐時資料自動寫成：現在有沒有下、幾點可能下、下多少、幾點停、明天幾度。
- **此刻**：濕度、風、氣壓、雲量、紫外線（0 到 11 的格尺）、這小時雨量，全部真實單位。
- **太陽**：一天 24 小時的橫條，金色是白天，紅色標記是現在；日出、日落、日照長度、今日最高紫外線。
- **未來 24 小時**：一格一度的像素柱狀圖，30 度以上紅色；下方藍格是降雨機率，一格兩成。可展開表格。
- **十三區**：照地理位置排成 4×5 的地圖格（左海右山、上北下南），藍底是正在下雨，▲ 是山區。點一格就切換整頁的預報地點。
- **未來七天**：日期、像素天氣圖、高低溫、降雨機率。
- **空氣品質**：AQI 與等級（良好綠、普通白、不良以上紅），PM2.5、PM10、O3、NO2。
- **氣象署官方預報**：需要授權碼，見下方。特報會以紅框顯示在頁面最上方。
- **最近三十天**：每日氣溫範圍（一格一度）與雨量（一格 5 毫米）。可展開表格。

支援鍵盤操作；頁面沒有動畫。中文用 DotGothic16，這是日文點陣字，「壢」等少數字會退回 Noto Sans TC。

## 資料來源

| 資料 | 來源 | 需要金鑰 |
|---|---|---|
| 即時、逐時、七天預報、三十天回顧 | [Open-Meteo Forecast API](https://open-meteo.com/en/docs) | 否 |
| 十三區邊界 | 內政部鄉鎮市區界線，取自 [g0v/twgeojson](https://github.com/g0v/twgeojson) 的 TopoJSON，簡化後內嵌於頁面 | 否 |
| 空氣品質 | [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) | 否 |
| 桃園市 36 小時預報（F-C0032-001）、天氣特報（W-C0033-001） | [中央氣象署開放資料平臺](https://opendata.cwa.gov.tw/) | 是 |

Open-Meteo 免費、允許瀏覽器直接呼叫，因此頁面可以純前端運作。十三區的座標取各區公所附近位置，模式格點解析度約 1–2 公里，山區與海邊的體感會和數值有差。

### 設定氣象署授權碼

1. 到 [氣象署開放資料平臺](https://opendata.cwa.gov.tw/user/authkey) 免費註冊並取得授權碼。
2. 頁面右上角「設定」，貼上授權碼後儲存。授權碼只存在這個瀏覽器的 localStorage。

若瀏覽器擋下跨網站請求，頁面會顯示錯誤說明；改用本機伺服器開啟通常可以解決。
