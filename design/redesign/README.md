## 第六個方向：像素

使用者指定保留像素風重做 `10-pixel`。10-pixel 的問題不是像素，而是 HP／MP 條、QUEST 等遊戲語彙把數值包起來、掃描線純裝飾、像素字體不支援中文只好混第二套。
06 的做法是讓像素成為單位：地圖上一格就是模式的一個 2 公里格點（用區界切出 301 格，並標出十三個取樣點，誠實呈現「一區一個數值」的資料結構）；逐時圖一格＝一小時×一度；七天圖一格＝一度。沒有遊戲語彙、沒有掃描線、沒有 CRT；中文用 Noto Sans TC（沒有完整支援正體中文的像素字體，硬湊會缺字），唯一的風格性像素是首屏的 5×7 點陣氣溫，天氣圖示是 8×8 方格的 inline SVG。

07 是依使用者回饋做的第二版：要的是 10-pixel 的色彩與排版，要避開的只有「看不懂」。所以保留 NES 調色盤、黑底白框的 RPG 對話框、點狀分隔線、像素天氣圖、Press Start 2P 與 DotGothic16 的搭配；拿掉 HP／MP／LV／QUEST 等遊戲語彙、掃描線、星空與漸層、打字機動畫與全部英文標題。數值一律用真實單位（%、hPa、UV 0–11 的格尺），逐時圖一格一度並標數字，十三區照地理位置排成 4×5 的地圖格。已知取捨：DotGothic16 是日文點陣字，「壢」等少數字會退回 Noto Sans TC。

## 五個方向怎麼呈現十三區

規範要求十三區保留空間關係、不降級成試算表。五頁各用一種做法：

- 01：階梯剖面（由低到高的次序）＋ 真實區界小地圖標階序。
- 02：真實區界輪廓圖，數字直接寫在區上，另附一張可捲動的表。
- 03：4×5 的地理格，左海右山、上北下南，每格一個大數字。
- 04：真實區界的降雨機率面量圖，五階藍墨。
- 05：真實區界圖，夜色底，還在下雨的區畫雨絲。

## 各頁取捨

- 03 與 05 不放三十天回顧：站牌只回答現在、接下來、哪一區；天色版把回顧留到另一頁。
- 05 是刻意的單一主題（夜間）；其餘四頁都有深淺兩色，深色版各自重新配過，不是反相。
- 每頁動態最多一處：只有 05 的「現在」月亮標記會緩慢呼吸，並尊重 `prefers-reduced-motion`。
- 圖示一律 inline SVG 單筆觸（03 的雨傘、01 與 05 的雨絲）；沒有 emoji、徽章、假內容。

## 已知限制

- 這些檔案是 Claude Artifact 的頁面片段，沒有 `<!doctype>`、`<html>`、`<head>`、`<body>` 外層；直接用瀏覽器開啟仍可顯示，獨立部署時請補上外層與 viewport meta。
- 區界與各區座標直接取自 `index.html` 的資料層（`GEO` 與 `DISTRICTS`），投影到 600×712 的 SVG。
- 各頁的正式版都需要接回 `index.html` 的 Open-Meteo 抓取；示範資料只用來看版面。

為什麼那十頁是 slop、本專案該怎麼做，見 `docs/agents/design-slop.md`；十個反例在 `design/vibe-slop/`。
